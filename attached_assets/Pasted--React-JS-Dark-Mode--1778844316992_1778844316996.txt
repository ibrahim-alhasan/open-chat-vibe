أنت مطور React JS متقدم. مطلوب منك إضافة دعم كامل للوضع الداكن (Dark Mode)
على الموقع، بحيث يتزامن مع تطبيق Expo React Native الذي يحقن الوضع عبر WebView.

══════════════════════════════════════════
كيف يعمل التطبيق الخارجي (المرسِل):
══════════════════════════════════════════

عند تبديل الوضع، يحقن التطبيق الكود التالي في WebView:

  localStorage.setItem('theme', 'dark' | 'light');
  document.documentElement.classList.remove('dark', 'light');
  document.documentElement.classList.add('dark' | 'light');
  document.documentElement.setAttribute('data-theme', 'dark' | 'light');
  document.documentElement.style.colorScheme = 'dark' | 'light';

══════════════════════════════════════════
المطلوب تنفيذه في الموقع (React JS):
══════════════════════════════════════════

1. قراءة الوضع الأولي من localStorage عند تشغيل التطبيق:
   - المفتاح: localStorage.getItem('theme')  → قيمة: 'dark' | 'light' | null
   - إذا كانت القيمة null، استخدم الوضع الداكن افتراضياً (dark)

2. تطبيق Tailwind CSS dark mode عبر الـ class strategy:
   في ملف tailwind.config.js:
   module.exports = {
     darkMode: 'class',
     ...
   }

3. في نقطة الدخول (main.tsx أو index.tsx)، قبل render:
   const savedTheme = localStorage.getItem('theme') ?? 'dark';
   document.documentElement.classList.toggle('dark', savedTheme === 'dark');
   document.documentElement.setAttribute('data-theme', savedTheme);
   document.documentElement.style.colorScheme = savedTheme;

4. إضافة MutationObserver للاستماع لتغييرات الـ class في حال حقن
   التطبيق الخارجي الوضع الجديد بعد تحميل الصفحة:

   const observer = new MutationObserver(() => {
     const isDark = document.documentElement.classList.contains('dark');
     // قم بتحديث state المشروع هنا إذا لزم الأمر
     document.dispatchEvent(new CustomEvent('themechange', {
       detail: { theme: isDark ? 'dark' : 'light' }
     }));
   });
   observer.observe(document.documentElement, {
     attributes: true,
     attributeFilter: ['class', 'data-theme'],
   });

5. إنشاء ThemeContext داخل React لتوزيع الوضع على المكونات:
   - اقرأ الحالة الأولية من: document.documentElement.classList.contains('dark')
   - اشترك في حدث 'themechange' لتحديث الـ state
   - لا تحتاج لزر toggle في الموقع لأن التحكم يأتي من التطبيق

6. في CSS / Tailwind، استخدم الألوان بهذا الأسلوب:
   <div className="bg-white dark:bg-gray-900 text-gray-900 dark:text-white">

   أو باستخدام CSS Variables:
   :root {
     --bg: #ffffff;
     --text: #111111;
     --surface: #f5f5f5;
   }
   :root.dark {
     --bg: #0f1426;
     --text: #ffffff;
     --surface: #1a2040;
   }

7. تأكد أن جميع المكونات تستخدم الألوان من الـ theme وليس قيم مباشرة (hardcoded).

الهدف النهائي: عندما يرسل التطبيق isDark=true، يتحول الموقع فوراً
للوضع الداكن بدون إعادة تحميل الصفحة.
